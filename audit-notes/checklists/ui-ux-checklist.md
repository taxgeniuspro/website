# UI/UX Audit Checklist

## Visual Consistency

### Colors
- [ ] Primary color consistent
- [ ] Secondary color consistent
- [ ] Error color consistent (red)
- [ ] Success color consistent (green)
- [ ] Warning color consistent (yellow)
- [ ] Text colors readable

### Typography
- [ ] Headings consistent
- [ ] Body text consistent
- [ ] Font sizes appropriate
- [ ] Line heights readable
- [ ] Font weights consistent

### Spacing
- [ ] Margins consistent
- [ ] Padding consistent
- [ ] Component spacing consistent

### Components
- [ ] Buttons styled consistently
- [ ] Forms styled consistently
- [ ] Cards styled consistently
- [ ] Tables styled consistently
- [ ] Modals styled consistently

---

## User Experience

### Navigation
- [ ] Clear where you are
- [ ] Easy to navigate
- [ ] Breadcrumbs (if deep pages)
- [ ] Back buttons work

### Feedback
- [ ] Loading states everywhere
- [ ] Success messages
- [ ] Error messages helpful
- [ ] Confirmation dialogs for destructive actions

### Forms
- [ ] Clear labels
- [ ] Placeholders helpful
- [ ] Required fields marked
- [ ] Inline validation
- [ ] Error messages near fields

---

## Responsive Design

### Mobile (320px)
- [ ] No horizontal scroll
- [ ] Touch targets 44px+
- [ ] Text readable
- [ ] Navigation accessible
- [ ] Forms usable

### Tablet (768px)
- [ ] Layout adapts
- [ ] Touch-friendly
- [ ] No content cut off

### Desktop (1024px)
- [ ] Full layout displays
- [ ] Sidebar visible
- [ ] Tables not cramped

### Large Desktop (1920px)
- [ ] No excessive whitespace
- [ ] Content readable
- [ ] Layout balanced

---

## Accessibility

### Images
- [ ] Alt text on all images
- [ ] Decorative images have empty alt

### Forms
- [ ] Labels associated with inputs
- [ ] Error messages linked to fields
- [ ] Required fields announced

### Keyboard
- [ ] Tab order logical
- [ ] Focus visible
- [ ] All interactive elements reachable
- [ ] Modals trap focus
- [ ] Escape closes modals

### Screen Readers
- [ ] Page titles descriptive
- [ ] Headings hierarchical
- [ ] ARIA labels where needed

### Color
- [ ] Sufficient contrast
- [ ] Not relying on color alone
