# Reference Site Analysis

## Why Reference Sites Matter

Tax Genius Pro combines several established patterns:
1. **CRM for lead/client management** → Compare to HubSpot, Salesforce
2. **Affiliate/referral tracking** → Compare to PartnerStack, Impact, Refersion
3. **Appointment booking** → Compare to Calendly
4. **Form/intake creation** → Compare to Typeform, JotForm

---

## Primary References

### 1. HubSpot CRM (hubspot.com)

**Why Chosen**: Industry leader in CRM for small/medium businesses

**Key Features They Have**:
- [ ] Contact management with custom fields
- [ ] Deal/pipeline stages with drag-and-drop
- [ ] Activity timeline on contacts
- [ ] Email tracking and templates
- [ ] Task management
- [ ] Reporting/analytics dashboard
- [ ] Team/user permissions
- [ ] Import/export contacts
- [ ] Search with advanced filters
- [ ] Mobile app

**UX Patterns**:
- Left sidebar navigation
- Contact cards with quick actions
- Inline editing
- Bulk actions via checkboxes
- Activity feed on record pages

**What Tax Genius Pro Should Match**:
- [ ] Clean contact list with search/filter
- [ ] Pipeline view for leads
- [ ] Activity history on contacts
- [ ] Role-based access control
- [ ] Export functionality

## Key Gaps to Investigate

1. **Activity History**: Does Tax Genius Pro track all interactions with a contact?
2. **Bulk Actions**: Can admins/preparers perform bulk operations?
3. **Import/Export**: Can data be imported/exported easily?
4. **Earnings Dashboard**: How clear is the affiliate earnings display?
5. **Performance Charts**: Are there visual analytics for affiliates?
6. **Booking UX**: How smooth is the appointment flow?
7. **Form Validation**: Are errors shown inline and clearly?
