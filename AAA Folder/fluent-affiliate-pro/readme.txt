= Migrate From Other Affiliate Plugins =
If you are using any other affiliate plugin then FluentAffiliate has a migration tool that will help you to migrate your data from other affiliate plugins to FluentAffiliate.

<h4> Migrate From AffiliateWp - FluentAffiliate</h4>
If you are an AffiliateWp plugin user then it's super easy to migrate to FluentAffiliate. Just install FluentAffiliate, Configure with basic settings, create your affiliates and then follow the following steps

* Go to FluentAffiliate -> Settings
* You can see the Migrator
* Select AffiliateWp from the dropdown
* Click on the migrate button
* It will take confirmation from you to migrate the data
* If you confirm then it will show you the details of the migration which includes the number of affiliates, referrals, and payouts
* Once you confirm it will take few minutes depends on your affiliate data size in AffiliateWp Plugin
* Once completed it will ask if you want to close the migration or leave it as it is. If you leave it then all data in AffiliateWp will remain as it is.

== Frequently Asked Questions ==
= Is it a self-hosted solution? =

Yes, FluentAffiliate is a 100% self-hosted solution. It will not connect with any of our SAAS servers. You own the data, and your data should be hosted on your hosting server.

= Is it GDPR-compliant? =

Yes, FluentAffiliate is fully GDPR-compliant. It does not store any personal data without the user's consent. It also has a data erasure feature that will help you to erase any user's data from the system.

= Will it affect my WordPress database? =

Absolutely not! From the very first, We were careful about this. It stores all the related data in custom database tables, so it will not affect your WordPress database. We built the application with VueJS, and it’s only run when you go to the admin dashboard of FluentAffiliate. Also, The Admin UI is superfast as It’s a SPA and communicates over ajax.
